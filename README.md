# ✨ Чудо-Словарь

Веб-приложение для запоминания английских слов по методу ярких мнемонических ассоциаций Самвела Гарибяна — из книги **«Английский без английского. Чудо-словарь ключей запоминания 3500 английских слов»**.

**Открыть приложение:** https://uud-ai.github.io/garibyan/

![Превью](og-preview.jpg)

## Что это

Метод Гарибяна вместо зубрёжки предлагает для каждого английского слова абсурдную, эмоционально яркую ассоциацию на русском языке, которая созвучна произношению слова и сама подсказывает перевод. Например:

> **God** [год] — Бог — *Целый (год), Богу молись!*

Приложение превращает 2872 таких ключа из книги в интерактивную колоду карточек.

## Возможности

- 🃏 **Карточки** — слово → транскрипция → ключ памяти → перевод, с отметкой «знал / не знал»
- 🔁 **Интервальное повторение** — слова, отмеченные «Знал!», возвращаются на повторение по расписанию (1 → 3 → 7 → 14 → 30 → 90 дней), «Не знал» сбрасывает на «повторить сегодня же»
- 📖 **Уроки** — слова разбиты на 58 уроков по 50, в том же порядке, что и в книге; можно учить урок за уроком
- 🎯 **Квиз** — проверка на узнавание перевода с вариантами ответов
- 🔎 **Поиск** — мгновенный поиск по слову, переводу или ассоциации
- 📊 **Прогресс** — статистика «знаю / учу / просмотрено»
- 🖼 Возможность прикрепить своё изображение к любому слову
- 🔊 Озвучка слова (Web Speech API)
- 📲 Устанавливается как приложение (PWA), работает офлайн

## Данные

Все 2872 слова (номер, слово, транскрипция, перевод, ассоциация) распознаны напрямую со страниц PDF-скана книги и вручную сверены. Формат одной записи:

```json
{"n": 1, "w": "God", "t": "год", "m": "Бог", "a": "Целый (год), Богу молись!"}
```

Живут они прямо в `index.html`, в массиве `WORDS` — отдельной базы данных нет.

### Известное ограничение

В исходном PDF-файле физически отсутствуют страницы со словами **№ 946–1569** (624 слова) — вырезаны или не попали в скан. Если у вас есть более полная версия книги, эти слова можно дозаполнить в том же формате.

## Технологии

Один файл `index.html` (HTML + CSS + JS, без сборки и зависимостей), `manifest.json` и `sw.js` для установки как PWA. Прогресс и загруженные картинки хранятся в `localStorage` браузера.

## Запуск локально

Файл статический — просто открыть `index.html` в браузере, либо поднять любой локальный сервер:

```bash
python -m http.server 8000
# или
npx serve .
```
